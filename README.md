# ItchLab.io

Estudio web de diseño y maquetación gráfica para proyectos de itch.io. Desarrollado por EternoDev.

## Características
- Edición modular de lienzos en resoluciones oficiales de itch.io (Cover, Banner, Landscape, Background).
- Persistencia local permanente con IndexedDB y StorageManager API.
- Catálogo de Google Fonts integrado con más de 1.900 tipografías libres.
- Adaptación proporcional de plantillas entre formatos manteniendo relación de aspecto.
- Descarga individual en PNG o empaquetado estructurado en ZIP.
- Previsualización en vivo de la ficha y cabecera de itch.io.

## Estructura del Proyecto
- `index.html`: Punto de entrada de la aplicación para GitHub Pages.
- `src/css/`: Hojas de estilo modulares (variables, layout, componentes, mockup).
- `src/js/`: Código JavaScript modular en ES Modules.
- `src/assets/images/`: Recursos divididos estrictamente por formato (`png`, `jpg`, `svg`).
- `src/html/`: Vistas y plantillas complementarias.
